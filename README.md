# Portfólio Pessoal - Nicholas Knopp

Portfólio pessoal moderno e responsivo, desenvolvido para apresentar minha trajetória, habilidades, certificados e projetos na área de tecnologia e dados.

**Acesse online:** https://nicholasknopp.github.io/Potfolio-Nicholas_Knopp/

## Funcionalidades
- Layout responsivo (mobile-first)
- Tema claro/escuro com persistência via `localStorage`
- Seções: Sobre, Formação, Habilidades, Cursos, Projetos e Contato
- Filtros interativos por categoria nas seções de Cursos e Projetos
- Animações de entrada com `IntersectionObserver`
- Função **Baixar Currículo** em PDF (via `window.print()` com estilos de impressão)
- Menu mobile e navegação com acessibilidade (ARIA e `prefers-reduced-motion`)

## Estrutura do Projeto

## Tecnologias Utilizadas
- HTML5 semântico
- CSS3 (Grid, Flexbox, variáveis CSS e `@media print`)
- JavaScript (ES6+)
- GitHub Pages (hospedagem)

## Como Executar
1. Clone este repositório.
2. Abra o arquivo `index.html` em um navegador web moderno.
